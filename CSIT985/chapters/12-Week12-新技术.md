## T113

**SDN的优点**

- 题型：简答；检索码：Q07；依据：老师样题（Week13 PDF p.16）。
- 知识点：SDN（软件定义网络）。

**Question:** What are advantages of SDN?

**中文题意：**SDN有哪些优点？

### 中文思路

SDN分离控制平面与数据平面。转发设备按规则处理流量，软件控制决定怎样管理规则，因此更容易改变网络行为，无需逐一单独配置每台设备。

可编程性让应用通过接口请求网络功能，能够支持更快配置变化、自动化以及多设备间更一致的政策。控制器较完整的网络视角也有助于协调流量处理与资源使用，而不只依靠孤立设备的决定。

分离允许控制软件与转发设备较独立地演进，使引入服务和适应需求变化更灵活。

收益取决于适当设计和实现。控制器可用性、安全、扩展性和接口兼容仍重要。逻辑集中不要求只有一台物理控制器，SDN也不自动保证更高速度或完全安全；应依据需求评价其价值。

### 英文参考答案（155词）

SDN separates the control plane from the data plane. Forwarding devices handle traffic according to rules, while software-based control decides how those rules are managed. This makes it easier to change network behaviour without configuring every device separately.

Programmability allows applications to request network functions through interfaces. It can support faster configuration changes, automation and more consistent policies across many devices. A controller's broader network view can also help coordinate traffic handling and resource use instead of relying only on isolated device decisions.

The separation allows control software and forwarding devices to evolve more independently. It can make introducing new services and adapting to changing requirements more flexible.

These benefits depend on suitable design and implementation. Controller availability, security, scalability and interface compatibility still matter. Logically centralized control does not require a single physical controller, and SDN does not automatically guarantee higher speed or complete security. Its value should be judged against the network's requirements.

只列“快、便宜、安全”；把controller当作所有数据包必经转发设备；把逻辑集中当物理单点。

变式：为什么“软件控制”可能简化策略修改，却不能单独证明吞吐量更高？

## T114

**SDN 三平面**

- 题型：简答；检索码：Q73；依据：范围扩展题。
- 知识点：SDN（软件定义网络）。

**Question:** Describe the three planes of SDN and how they interact.

**中文题意：**描述SDN三个平面的分工。

### 中文思路

application意图/服务；controller全局策略；data匹配转发/状态回报。

### 英文参考答案（132词）

SDN separates the application, control and data planes. The application plane contains network services and applications that express requirements and use a view of the network.

The control plane is managed by one or more controllers. It maintains information about the infrastructure, makes or implements policy decisions and programs forwarding behaviour. The data plane contains physical or virtual forwarding devices. They process traffic according to rules and report relevant network state.

The separation allows control logic and forwarding to evolve more independently. For example, an application can request a traffic policy, the controller translates it into device rules, and switches apply those rules to packets. This supports programmability and coordinated management. A logically centralized view does not require one unprotected physical controller. Controller architecture, communication and failure handling remain important design decisions.

application plane不是交换机端口；controller不等于逐个代替交换机传所有数据。

变式：Trace a policy request from application to controller to switch.

## T115

**SDN interfaces 与 OpenFlow**

- 题型：简答；检索码：Q74；依据：范围扩展题。
- 知识点：SDN（软件定义网络）。

**Question:** Explain northbound, southbound and east–west interfaces in SDN.

**中文题意：**解释三类接口及OpenFlow的角色。

### 中文思路

north应用↔control；south控制↔设备；eastwest控制器；OpenFlow一种south协议。

### 英文参考答案（127词）

A northbound interface connects the SDN control plane with applications or higher-level services. It lets applications obtain network information and express requirements. A southbound interface connects controllers with forwarding infrastructure so that control decisions can be applied to devices.

An east–west interface supports communication between controllers in a distributed control architecture. OpenFlow is one example of a southbound protocol; it is not the only possible SDN interface or the complete definition of SDN.

In an OpenFlow-style system, a switch matches packets against flow-table entries and performs the associated actions, such as forwarding or dropping. Controller involvement depends on installed rules and configuration. The interfaces must support the needed functions, security and scale. Different northbound APIs can also create portability and integration challenges between applications and control platforms.

northbound在不同管理架构语境有不同上层对象；先说明这里是SDN。

变式：What does an OpenFlow switch do when matching a flow entry?

## T116

**SDN 的限制与部署条件**

- 题型：简答；检索码：Q75；依据：范围扩展题。
- 知识点：SDN（软件定义网络）。

**Question:** Discuss the challenges and trade-offs of deploying SDN.

**中文题意：**讨论SDN挑战及收益条件。

### 中文思路

NBI不统一；控制器安全/规模/分布一致性；QoS/IoT；迁移验证。

### 英文参考答案（130词）

SDN can simplify coordinated control and make networks programmable, but the controller and its interfaces become important parts of the system. Controller failure or compromise can affect many devices, so availability and security need explicit design.

Scalability depends on control workload, platform architecture, state collection and flow-rule management. Distributed controllers can improve resilience and capacity, but they require coordination. Different northbound interfaces can make applications harder to move between platforms. Supporting QoS and diverse environments, including IoT, adds further requirements.

A practical deployment should compare these costs with the expected benefits. Test device support, policy behaviour, management access and recovery under failures. SDN does not automatically make a network secure, reliable or fast. Those outcomes depend on how the architecture is designed, operated and measured against the organization’s actual requirements.

不能声称SDN自动消除全部故障或兼容性问题。

- 题型：简答；检索码：Q76；依据：范围扩展题。
- 知识点：SD-WAN（软件定义广域网）。

**Question:** What is SD-WAN, and what benefits and conditions should be considered?

**中文题意：**解释SD-WAN及其收益条件。

### 中文思路

软件管理广域网；应用体验/云连接/安全/简化；仍依赖底层链路。

### 英文参考答案（135词）

SD-WAN applies a software-based management approach to a wide area network. A WAN connects geographically separated networks, such as the LANs of different campuses or offices.

SD-WAN can make policy management more consistent and improve how applications use available WAN connectivity. The course highlights better application experience, stronger managed security, optimized cloud connectivity and simpler management. These are potential benefits rather than outcomes guaranteed by the name alone.

The design must still consider the capacity, delay, loss and availability of the underlying links. It also needs suitable security policies, monitoring and controller resilience. For example, centrally applying a policy for teaching traffic can simplify operation across campuses, but it cannot remove a physical outage unless an alternative path exists. Select SD-WAN when its capabilities address the organization’s flows and management needs at an acceptable cost.

### 英文参考答案（134词）

Network automation uses software to perform tasks in the network life cycle, including configuration, management, testing, deployment and operation. The course gives SDN, Ansible, Puppet and Python scripts as examples of approaches or tools.

## T120

**NFV 与三要素**

- 题型：简答；检索码：Q79；依据：范围扩展题。
- 知识点：NFV（网络功能虚拟化）。

**Question:** Define NFV and describe NFVI, VNFs and MANO.

**中文题意：**定义NFV及三项架构元素。

### 中文思路

软件网络功能脱离专有盒子；infrastructure资源；VNF功能；MANO管理编排。

### 英文参考答案（126词）

Network Function Virtualization, or NFV, implements network functions as software on shared, general-purpose infrastructure. For example, a firewall or load-balancing function can run as a software instance instead of requiring a separate dedicated appliance for every deployment.

The course identifies three main elements. NFV infrastructure, or NFVI, provides the computing, storage, networking and virtualization resources. Virtual network functions, or VNFs, provide the actual network functions. Management and orchestration, or MANO, manages their deployment and life cycle and coordinates resources.

Separating functions from dedicated equipment can improve flexibility and allow services to be placed or scaled when needed. However, performance, isolation, shared-resource contention and infrastructure failure still matter. Virtualization changes how functions are delivered; it does not remove the requirement to test service capacity, availability and security.

VNF是功能软件，NFVI是承载资源，MANO不是转发业务本身。

## T121

**SDN 与 NFV 的区别和组合**

- 题型：简答；检索码：Q80；依据：范围扩展题。
- 知识点：NFV（网络功能虚拟化）。

**Question:** Compare SDN and NFV and explain how they can work together.

**中文题意：**比较SDN/NFV并说明组合方式。

### 中文思路

SDN分离control/data；NFV分离function/专用设备；一个管连接，一个软件化功能。

### 英文参考答案（138词）

SDN separates network control from data forwarding and makes forwarding behaviour programmable. NFV separates network functions from dedicated physical appliances and runs those functions as software on shared infrastructure.

They address different forms of flexibility. SDN concerns how traffic is controlled and connected. NFV concerns how services such as firewalls or load balancers are implemented and deployed. One does not automatically require the other.

They can work together. NFV can deploy a virtual firewall and other functions, while SDN can steer relevant traffic through them according to policy. MANO manages function life cycles and resources, while controllers manage appropriate connectivity and forwarding. The combined design must still consider capacity, availability, security and coordination. A software function is not automatically fast or reliable enough merely because it is virtual, and programmable connectivity does not itself provide the function’s protection.

不要把NFV简单定义成SDN另一个名字。

变式：Design a virtual firewall chain and identify each technology’s role.

## T122

**AI、ML、DL 与学习类型**

- 题型：简答；检索码：Q81；依据：范围扩展题。
- 知识点：ML in networking（机器学习在网络中的应用）。

**Question:** Explain AI, ML and DL and compare supervised, unsupervised and reinforcement learning.

**中文题意：**解释包含关系及三类学习。

### 中文思路

AI⊃ML⊃DL；有标签、无标签找结构、动作奖励；不是都需人工标签。

### 英文参考答案（137词）

Artificial intelligence is the broader field of systems performing tasks associated with intelligent behaviour. Machine learning is a part of AI that learns patterns from data or experience. Deep learning is a part of ML that uses multi-layer neural-network approaches.

Supervised learning uses examples with target labels or values. Classification predicts a category, while regression predicts a numerical value. Unsupervised learning looks for structure in data without supplied target labels, such as groups of similar traffic. Reinforcement learning learns actions through interaction and reward feedback.

These approaches suit different network tasks. A labelled attack dataset may support classification, traffic measurements may support rate prediction, and interaction with a network environment may support resource-control decisions. The learning method must match the task, available data and operational limits. No method guarantees useful predictions simply because it is called AI.

### 易错、变式与反馈

ML不全是监督学习；DL不等于整个AI。

变式：Distinguish regression and classification; map a network task to a learning category.

## T123

- 题型：简答；检索码：Q82；依据：范围扩展题。
- 知识点：ML in networking（机器学习在网络中的应用）。

**Question:** Describe an ML workflow for networking, its applications and limitations.

**中文题意：**说明ML流程、网络用途和局限。

### 中文思路

历史数据→建模/评价/优化循环→新数据预测；routing/IDS/QoS/resources；数据偏差隐私算力。

### 英文参考答案（135词）

An ML workflow starts with suitable historical data. Model building, evaluation and optimization form an iterative process. After evaluation, the model can make predictions or support decisions on new data. As a practical extension, new conditions should be monitored because old patterns may no longer represent the network.

Networking applications include predicting traffic volume or link quality, intrusion detection, routing support, QoS improvement and resource allocation. These applications can assist engineers but still require suitable operational controls.

The course highlights computational load and the trade-off with accuracy, data availability and privacy, imbalanced datasets and the need for realistic testing. A model trained mostly on normal traffic may perform poorly on rare attacks. Evaluate results against the actual task and consider the consequences of wrong predictions. More complex models are not automatically better for every network.

训练集上高准确率不能直接证明真实环境可用；罕见攻击可能被掩盖。
