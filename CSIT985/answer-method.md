# 怎样参考Moodle组织答案

这份方法用于考前训练。逐题的“组织方式”解释现有参考答案各段的任务；“答题路线”帮助你根据实际题干重新组织；“Moodle查阅”告诉你回原资料核对什么。它们都是教学辅助，不是官方评分细则。

## 先明确考试可查什么

按已核对的Assessment Task 5公告，正式考试是个人独立完成：10道简答，各3分、约150词；1道长答，10分、约1000词；总时长180分钟；范围为Week1–12 lectures，没有Packet Tracer题。

可查的是课程Moodle发布的lecture notes、workshop notes，以及Subject Reading List所列书籍；可通过课程Reading List链接在线访问这些书。题库网页、这里的答题提示、自制笔记和AI工具不自动成为考试许可资料。考试中只访问明确允许的材料；不从任何来源向考试答题框复制粘贴，理解后独立组织并手动输入。

规则依据：[Moodle课程的Assessments and submissions](https://moodle.uowplatform.edu.au/course/section.php?id=730280)中的Assessment Task 5。下方的时间分配、句式和查阅练习是AI整理的建议，不是公告要求；若后续公告更新，以实际考试说明为准。

## 一道简答题的六步流程

1. **拆题。** 先找动词、对象、数量和附加条件。Compare A and B and explain when each is useful包含“比较”和“适用场景”两个任务；all、two、three不能忽略。
2. **先回忆路线。** 在脑中或答题框先排出3–5个内容块；列举题按题目数量完整保留。先确定要证明什么，再去查资料。不要从第一周开始逐页浏览。
3. **定向核对。** 回忆所属week，在允许的原资料中查本题关键词。优先核对忘记的项目、正式术语、顺序、图中关系、公式、单位、条件和例外。原页提供事实与关系，你负责把它们连成回答。
4. **组织英语。** 第一两句直接回答；主体按题型展开；每个关键点补作用或原因；用题目场景作说明；需要时保留限制条件。使用常见短句，专业术语保持准确。
5. **手动输入。** 根据已理解的提纲独立表达。把PPT项目变成完整的因果、比较或过程说明；仅替换原句几个单词不等于完成理解和组织。此题库中的英文是训练示范。
6. **对题检查。** 逐项看是否完成所有子问、数量是否齐全、专业词与数字是否正确、条件是否保留、篇幅是否接近要求。3分不自动等于3个知识点；about 150也没有给出已确认的硬性上下限。

## 按动词选组织方式

| 题型 | 答题顺序 | 最容易漏掉的部分 |
| --- | --- | --- |
| Define / What is，定义 | 是什么 → 关键特征 → 作用或区别 | 定义的适用范围 |
| List / Identify / Describe all，列举 | 完整清单 → 每项含义或功能 → 必要联系 | all或指定数量；只列名不解释 |
| Explain / Why，解释原因 | 直接回答原因 → 机制或因果链 → 结果 → 例子/条件 | 只有定义，没有说明为什么 |
| Compare / Differences，比较 | 相同维度对照A/B → 各自收益与代价 → 场景/条件 | 各写一段却不指出相同维度的差别 |
| Describe the process / How，过程 | 输入 → 有序步骤 → 每步作用 → 输出/验证 | 步骤顺序、产物及反馈 |
| Advantages / Evaluate / Recommend，收益与评价 | 收益或选择 → 机制与依据 → 对需求的帮助 → 限制/取舍 | 只说更快更好，未解释机制或条件 |

题型可组合。先按实际子问决定篇幅，不把所有题强行写成同一种三段式，也不为凑词数加与题目无关的定义。

## 可以反复练的英文表达

| 表达 | 中文意思及用途 |
| --- | --- |
| X refers to … | X指的是……；用来给定义。 |
| A uses …, while B uses … | A使用……，而B使用……；同一维度比较。 |
| This is important because … | 这很重要，因为……；直接回答why。 |
| This can lead to … | 这可能导致……；把机制连到结果，can保留条件性。 |
| The process begins with … It then … Finally, … | 过程先……，然后……，最后……；串联步骤。 |
| This is suitable when … | 当……时适用；交代应用条件。 |
| However, this depends on … | 不过，这取决于……；保留限制。 |

优先记完整表达和内容路线。句式只是容器，不能替代准确的专业内容。

## 用原资料回答：三个具体示范

**T031：Why要看frequency与duration？** 先定位Week4的Application behaviour相关页，核对frequency、duration、用户数、数据大小等因素。把“多久一次”和“持续多久”连成“事务可能重叠→同时活跃负载→容量和延迟影响→估算与调度”。查到了两个定义以后，仍要自己解释中间因果；duration长也不自动代表data rate高。可先写：This is important because these factors help estimate concurrent activity and busy periods. 这句话的意思是“这些因素有助于估计并发活动和繁忙时段，所以很重要”。

**T099：比较in-band与out-of-band。** 在Week9管理资料中核对两者的management path。按“路径是否共享、业务网故障时能否访问、成本复杂度、安全条件”逐项组织。示范开头：In-band management shares paths with user traffic, while out-of-band management provides an alternative management path. 即“带内与用户流量共享路径，带外提供替代管理路径”。后面解释共享故障、恢复收益和代价，并保留设备失电时带外也未必可用的条件。

**T105：列设计过程产物。** 在Week11的Design Products页先核对完整五项：network blueprints、component plan、vendor/equipment/service-provider selections、traceability、design metrics。看齐名称后，每项补一句“它描述什么、帮助做什么”。第一句可以先报五类清单，再逐项展开；不要用一个很长的校园例子挤掉必答项目。

这些定位是本题库已有来源的使用示范。考试原题若换动词、对象、数量或场景，重新拆题；不要只看到熟悉术语就复写练过的整段答案。

## Moodle定位与查找的练法

- 每题先记“所属week＋主题英文”，再记常用关键词；精确物理页码用于加速核对。题库页码从PDF第1页起计，包含封面，可能与幻灯片印的页码不同。
- 本题的Moodle链接打开对应资源，不保证自动跳到所列页。进入PDF后用阅读器的查找功能搜索关键词；如果页面是图片或搜索无结果，用物理页码和标题定位，并看图与箭头。
- 查列表要确认是否完整；查比较要找同一组维度；查why要找变量关系；查过程要看顺序与反馈；查计算要核对变量、单位、适用条件。不能把搜索命中的一句话当成全部答案。
- 找不到时先换课件中的同义词或相邻标题；一次定向尝试仍无进展，可先完成已知部分、留下待补位置，再做别题。不要把大量时间消耗在漫无目的浏览。
- 不能为了保留此题库的提示而把它上传到Moodle或在考试中另开未许可网页。训练目标是能离开题库，只用允许的原资料作答。

## 计算、图题和长答怎样使用资料

**计算题：** 已知量/单位 → 公式或规则及条件 → 代入步骤 → 带单位的结果 → 验证。查资料是为了确认方法，不是把课件原例的数字直接搬来。Subnetting检查容量、边界、network/broadcast、可用范围与不重叠；availability检查观察窗口；速率区分bit/byte和payload/wire。

**Flow图题：** 原图业务条件 → source/sink表 → 方向与性能要求 → 显式假设 → 各类flow图 → 合并图和核对。缺少端点信息时说明假设；逻辑flow map不等于已知物理线缆图。

**长答：** 把实际题目拆成多个小问题，并为每个子问安排一个内容块。按需要分别查几份原资料，用同一案例串起“需求→机制/方案→收益与代价→验证”。题目要求三个威胁时，每个都写具体资产、威胁、后果与回应；不能只列三个攻击名称。约1000词的示范用于训练完整论证，不要求记住所有原句。

## 时间分配：先用模拟校准

可先试：快速读题和分配任务5分钟；10道简答共110分钟（平均约11分钟/题，含查资料与输入）；长答50分钟；最终检查15分钟。合计180分钟。若界面不允许自由切题或回看，按实际导航规则调整。

这是起始训练方案。你尚未提交完整限时手打样本，不能保证该速度适合你。模拟时记录“拆题、定位、组织、输入、检查”各用多久，再调整。简答卡住时先保住已知且相关的内容；长答提前留够时间，不把所有时间用于查简答。

## 三轮训练，逐步减少提示

1. **理解轮：** 看题内答题路线，对照英文段落，说出每段的任务；只记顺序与关键词，不急着逐字记全文。
2. **检索轮：** 收起英文答案，看题目后只打开允许的原课件或workshop资料；自己列路线并手动写。复习阶段可再展开题库核对遗漏。
3. **模拟轮：** 关闭题库和所有提示，只留明确允许的资料，计时手打；完成后再回题库核对。分别记录概念不清、找页慢、组织困难、英文表达或输入速度问题。

一次自查：不看参考答案时，能否说出本题的所有任务、答题顺序、应查的week和关键词，并写出带原因与条件的完整回答？看懂示范和能独立完成是两个不同阶段。
