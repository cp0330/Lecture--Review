全部131题已补“任务类型、建议答题路线、现有参考答案的组织方式、Moodle页码与搜索词、查到后应确认的内容、换问法时的调整”。原英文参考答案与编号保留。99道简答逐段说明；计算、图题、长答采用各自的步骤或章节结构。

[三色参考答案说明](answer-colors.md)：全部英文参考答案按片段分色。蓝色知识点可回资料核对；紫色为可复用语言；橙色为推理、应用、例子、条件和结果。工具栏可关闭分色，蓝色悬停有资料页码，紫色悬停有中文意思。

先读[怎样参考Moodle组织答案](answer-method.md)。在[在线题库](https://cp0330.github.io/Lecture--Review/)中，点击“答题思路与Moodle查阅”查看某题；“只看答题思路”显示提示并收起完整答案；“隐藏答案自测”同时收起提示和答案。

正式考试只使用已明确允许的课程原资料；此题库与教学提示不自动进入许可清单。按拆题→回忆路线→定向核对→组织→手动输入→检查练习。
