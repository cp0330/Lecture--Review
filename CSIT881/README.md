## 作答和判定

1. 写下你的答案，或拖动代码块。手机和键盘也可用 ↑ 和 ↓。
2. 点击「提交作答」锁定这一轮。拖放题会核对顺序。程序、函数和手工推演题在提交后自行查看参考答案，其中 Python 程序可复制到本地 Python 或 Colab 核对。
3. 独立提交并核对通过记为「独立通过」。提交前看过提示或答案且核对通过记为「提示后通过」。需要再练的题记为「待复测」。初始状态均为「待测」。
4. 「开始新一轮」清空当前作答，保留错因备注。草稿、顺序、备注和状态存放在当前浏览器。
