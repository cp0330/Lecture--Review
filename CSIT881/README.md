## 作答和判定

1. 先看英文题干、样例和提交要求。需要定位原材料时展开「来源与页码」。Moodle 截图与文本 Lab 按题号、主题或行号定位。
2. 作答后点击「提交作答」。拖放题支持鼠标和 ↑ / ↓，提交后自动核对顺序。完整程序、函数、类和推演题可对照参考答案自评。Python 程序可以在本地 Python 或 Colab 运行。
3. 独立提交且核对通过记为「独立通过」。提交前看过提示或答案且核对通过记为「提示后通过」。需要再练的题记为「待复测」。
4. 草稿、顺序、备注和状态保存在当前浏览器。原有题号和进度继续可用，「开始新一轮」清空当前作答并保留错因备注。

## 考点与变式

| 考点 | 新变式改了什么 |
| --- | --- |
| 输入与精确输出 | 从样例反推栏宽，核对负数和满宽文本。根据总宽而非内宽排版，处理无有效算式的情况。 |
| 条件分支与边界 | 折扣前后金额用于不同判定。优先处理完成状态，再按分数阈值分类。 |
| 循环、遍历与统计 | 划分负数、零和正数。倒序遍历包含端点的区间并处理无匹配。 |
| 函数规格与返回值 | 同时返回首次索引和匹配总数。迁移递归停止条件到数字求和。 |
| 类与实例方法 | 检查对象状态互相独立。让显示方法调用实例判断方法。 |
| 列表与字典 | 按首次出现顺序报告重复项。累加分组数据并保持原记录。 |
| 异常与输入验证 | 无效输入后继续，退出标记优先。区分转换错误与范围错误。 |
| 文本与 CSV 文件 | 把字段转成整数再筛选，处理含逗号的引号字段。追加非空行并保留已有数据。 |
| 算法分析与提前返回 | 计算不同命中位置的比较次数。在已排序列表中利用较大值停止。 |
| 排序与逐轮推演 | 用带标签的重复键检验相对顺序。计算冒泡提前停止前的比较次数。 |
| 链表与引用更新 | 在第一次匹配后插入节点。区分单节点和普通情况的尾删。 |
| 栈与队列 | 区分空栈、类型不匹配和遗漏闭符号。重排空队列及非空队列的入队操作。 |
| 树遍历与 BST | 推演带缺失子节点的遍历、深度和树高。按比较结果只选择 BST 的一条子路径。 |
