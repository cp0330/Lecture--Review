CSIT884 / Run and keep your work

作答、运行、对照。

代码框保存文字；自己的网页在浏览器中运行。表单和天气练习使用下载包内的本地服务。

运行练习

  1. 下载练习包并解压。
  2. 在文件夹中运行 python3 serve.py；macOS 也可打开 Start-practice.command。需要 Python 3。
  3. 保持服务窗口开启，访问 http://127.0.0.1:8765/questions.html。
  4. 把自己的 HTML 保存到 my-work/。例如 http://127.0.0.1:8765/my-work/a4.html。这样 ../assets 与 ../data 的路径可以直接使用。
  5. 检查输出、交互、参数与指定技术，然后在学习页面记录完成情况。

服务提供 /search、/short-url 和 /weather；GitHub Pages 没有这些接口。天气是固定练习数据。Q14 通过 HTTP 读取 JSON。A1-2 使用给定的完整在线图片 URL；图片也打包在 assets，可另用绝对 localhost URL 练习离线适配。

新版与旧版草稿

新版使用独立记录，旧 884-bank-Qxx 和检查项不会被删除。打开对应 Q 题的 Previous drafts and attempts，可查看旧稿并选择复制；旧勾选不会当作新题评分。

New attempt 会保存当前尝试后开始空白。My Answer、Hints、Explanation、Reference Answer 分开显示，切回作答保留代码与光标。

移动和备份

Export all progress 导出 v2 JSON，包含本次草稿、旧版本及历史尝试。Import backup 接受 v1/v2；v1 作为旧稿保留，v2 在确认后替换对应记录。

不同 origin、浏览器和设备不共享 storage。网站与 localhost 间迁移时先导出，再在另一处导入。浏览器清除数据会删除本地草稿。
