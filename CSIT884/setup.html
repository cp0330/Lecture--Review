CSIT884 / Local practice

Write, run, compare.

Use the hosted workspace for reading and drafts. Use the local pack for the service exercises.

Start the practice server

  1. Download the practice pack and unzip it.
  2. On macOS, double-click Start-practice.command. It needs Python 3. If the system does not open it, open a terminal in the extracted folder and run python3 serve.py.
  3. Keep the server window open. Visit http://127.0.0.1:8765/questions.html.
  4. Save your own q01.html, q02.html, etc. in my-work/. For example, open http://127.0.0.1:8765/my-work/q01.html. The ../assets/ and ../data/ paths then match the reference answers.
  5. Compare the required output, state changes and method. The draft box records text and does not execute your code.

Q07, Q08 and Q25 submit to /search, which shows received parameters. Q15 requests /weather, which returns fixed practice data. These endpoints exist in serve.py, not on GitHub Pages. Q14 also needs HTTP access to its JSON files.

Other HTML examples can be opened through the same local server. Test storage with a consistent protocol, host and port.

Keep your work

Use Export all progress on the question page to download a JSON backup. Import it on another copy of the workspace. The import asks before replacing saved work.

The website and localhost have different origins. They do not share drafts automatically. The same applies to another browser or device. Export and import a backup to move your work.
